# Imola (Imouto Language)

See [mapping rule](mapping.md).

## Pronouns

### Personal

The nominative and objective forms are identical.

Singular.

| Imola | Reading | Meaning           |
| ----- | ------- | ----------------- |
| ai    | I       | I, me             |
| yu    | you     | you               |
| hi    | he      | he, him, she, her |
| it    | it      | it                |

Plural. Just add 'ol' (all).

| Imola  | Meaning    |
| ------ | ---------- |
| ai ol  | we, us     |
| yu ol  | you all    |
| hi ol  | they, them |

### Possessive

Add 'no' (borrowed from Japanese) after personal pronoun.

| Imola    | Meaning   |
| -------- | --------- |
| ai no    | mine      |
| yu no    | yours     |
| hi no    | his, hers |
| it no    | its       |
| ai ol no | ours      |
| hi ol no | theirs    |

### Reflexive

Add 'no self' after personal pronoun.

| Imola         | Meaning          |
| ------------- | ---------------- |
| ai no self    | myself           |
| yu no self    | yourself         |
| hi no self    | himself, herself |
| it no self    | itself           |
| ai ol no self | ourselves        |
| yu ol no self | yourselves       |
| hi ol no self | themselves       |
